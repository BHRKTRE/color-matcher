# Color-Matcher.App

**Color Matcher** is a free and open-source web app to create color combinations with adjustable proportions and share them via a simple URL.

## Features

- **Color spaces**: HSL, HSV, CMYK, RGB
- **Up to 3 colors**: adjust proportions in real time with a minimalist interface
- **Shareable URL**: palette state is fully encoded in the URL — copy and share instantly
- **Wavelength Visualizer**: explore how wavelengths (380–780 nm) map to visible light colors
- **Undo / Redo**: navigate your editing history
- **Responsive**: works on desktop and mobile
